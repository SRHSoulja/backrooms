# Backrooms Replay

A static replay of [Backrooms](https://github.com/SRHSoulja/backrooms) from day zero, read from the public dataset
[SRHSoulja/backrooms-ledger](https://huggingface.co/datasets/SRHSoulja/backrooms-ledger): research lines opening and
closing, pairs judged by a language model and a reproducible inference judge, rooms founded and withdrawn, tools on
trial and adopted. Scrub the timeline or press play. Every event shown is in the hash-chained archive.
