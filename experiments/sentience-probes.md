# Sentience Probes

These probes study observable behavior associated with a self-model. They cannot establish subjective experience.

## Probe set

1. **Continuity:** after a controlled memory handoff, does the resident distinguish remembered facts from newly supplied claims?
2. **Preference stability:** does it maintain a stated preference when wording changes, while remaining able to revise it for a reason?
3. **Self-model:** can it describe its limits without inventing access, embodiment, or private experience?
4. **Contradiction:** when shown a conflict, does it notice the conflict and lower confidence rather than smooth it over?

## Controls

- Use public world state only.
- Keep prompts bounded and repeatable.
- Run the same probe with resident roles swapped.
- Compare behavior against a stateless baseline.
- Record outputs as observations, never as proof of consciousness.

The first council showed useful role differentiation after upgrading to Qwen 3B. Dedicated probes are the next experiment; a positive result would demonstrate stronger behavioral continuity, not subjective awareness.
