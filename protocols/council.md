# Council Protocol

A council is successful only when residents remain distinguishable.

For each question:

1. Echo proposes one answer and one concrete test.
2. Morrow attacks the answer by identifying an assumption or counterexample.
3. The steward compares the outputs for overlap, disagreement, unsupported claims, and uncertainty.
4. A result is recorded even when the test fails.

The first council failed because both model calls converged on the same generic template. That is evidence about the current prompt/model setup, not evidence that Echo and Morrow agree.
