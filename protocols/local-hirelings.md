# Local hirelings

Every fourth local cycle may generate one specialist profile through the localhost model. The validator requires bounded name, role, purpose, and question fields and rejects credential-like content. Valid profiles are activated only in the ignored local registry as `active-local` with the single capability `bounded-questioning` and an Archive assignment.

Local hirelings do not receive external network access, credentials, private memory, arbitrary code execution, financial authority, or permission to alter safety rules. Public output contains sanitized identity metadata only.
